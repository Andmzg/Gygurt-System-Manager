# Gygurt-System-Manager

Gygurt System Manager V2.1 is a custom-built, mobile-first ERP solution designed to centralize and automate the core operations of Gygurt, a local yogurt production business. The system focuses on eliminating manual administrative errors and streamlining the sales-to-delivery workflow.

Key Features
Order Management Module (Nuevo Pedido): Automates sales registration with integrated real-time pricing logic based on product variety.

Automated Document Workflow: Utilizing Google Drive APIs, the system automatically generates professional delivery notes (PDF) and archives them in specific cloud folders for systematic record-keeping.

Accounts Receivable Tracking (Cobranza): Provides a mobile interface for real-time monitoring of debtor lists and payment history.

Data Analytics Integration: Connects seamlessly with Google Looker Studio to provide live dashboards for inventory and financial health monitoring.

Technology Stack
Backend: Google Apps Script (JavaScript-based).

Frontend: HTML/CSS (Custom UI) & AppSheet for mobile deployment.

Database & Storage: Google Sheets & Google Drive API.

Visualization: Google Looker Studio.

Impact
Efficiency: Achieved an 80% reduction in manual administrative tasks.

Accuracy: Eliminated manual pricing errors through centralized logic.

Accessibility: Enabled 100% remote management of business operations via mobile devices.
